路线 A：装到 WorkBuddy

最简版

把安装包直接发给 WorkBuddy

把 jasp-bridge-0.2.0-portable.zip 拖进 WorkBuddy 对话框，然后发这段话：

这是我下载的 JASP-Bridge 安装包。请帮我：
1. 解压到一个合适的位置；
2. 检查我电脑上是否安装了 JASP；
3. 如果已安装，运行包里的 install.ps1 完成安装；
4. 安装完成后告诉我怎么验证。
不要覆盖已有的 runtime 和 sessions。

前提：你的 WorkBuddy 版本允许执行本地命令或文件操作。如果它不能执行，就用下面的手动三步。

手动三步

  1. 1
    解压 zip

    右键压缩包 → 解压到当前文件夹。不需要改任何文件。

  2. 2
    在解压后的文件夹里打开终端

    在文件夹空白处 Shift + 右键，选择“在终端中打开”或“在此处打开 PowerShell 窗口”。

  3. 3
    运行安装命令 
    powershell -ExecutionPolicy Bypass -File .\install.ps1

    不需要 cd 到某个固定目录，也不需要改脚本里的路径。

注意 JASP 必须先装好。 安装脚本会从你电脑上的 JASP 复制一份计算引擎（约 1.7 GB）。不需要单独装 R、Node 或 jaspTools。

安装完成后怎么验证

重启 WorkBuddy，然后在对话里说：

检查 JASP 状态

正常情况下你会看到类似：

JASP：已找到
JASP 运行时：可用
Rscript：可用
jaspTools：0.20.1
无头 R：可用

看到“无头 R：可用”就说明能自动分析了。如果显示不可用，先确认 JASP 是否装好，再重新运行 install.ps1。

路线 B：用 DeepSeek / 豆包的模型

先说清楚 DeepSeek、豆包的官方桌面版，通常不能直接装这个插件。

它们没有“加载本地插件”的入口。你能在设置里找“MCP / 插件 / 工具 / 自定义连接器”；如果找不到，就不能直接接。

可以这样理解：

脑
DeepSeek / 豆包 负责思考和对话
线
JASP-Bridge 把大脑和计算器接起来
算
JASP 真正算统计

官方桌面版像“没有插线口的手机”；你需要换一个“有插线口”的聊天软件，比如 Cherry Studio。

四步接好

  1. 1
    装一个能装插件的聊天软件

    推荐 Cherry Studio（免费）。Cline、Roo Code 也可以，但更适合技术用户。

  2. 2
    把模型的“钥匙”填进去

    在聊天软件的“模型服务 / 提供商”里，选择 DeepSeek 或豆包，粘贴 API Key。

    模型地址模型名
    DeepSeekhttps://api.deepseek.com/v1deepseek-chat
    豆包https://ark.cn-beijing.volces.com/api/v3ep-... 接入点

    豆包要在火山方舟开通，步骤比 DeepSeek 多；看不懂就找会电脑的朋友帮一次。

  3. 3
    把 JASP-Bridge 接上

    在聊天软件的“MCP 服务器 / 插件 / 扩展”里添加服务器，填两个路径：

    程序：<你的安装目录>\node.exe
启动文件：<你的安装目录>\src\server.js

    或者直接导入 configs/mcp/jasp-bridge.json，再把 <你的安装目录> 换成实际路径。

  4. 4
    重启并验证

    重启聊天软件，在对话里说“检查 JASP 状态”。看到“无头 R：可用”就行。

不想装额外软件？

也可以只用官方桌面版，但只能让模型帮你规划分析步骤，你自己在 JASP 里点，再把结果贴回对话让模型解释。这不是自动执行。

路径怎么找

方法 1：复制文件地址

在资源管理器里按住 Shift，右键文件，选择“复制文件地址”。

方法 2：拖进 PowerShell

输入 cd （后面有空格），然后把文件夹拖进窗口，按回车。

方法 3：拖进对话

直接把 CSV 或模板拖进 WorkBuddy 对话框，让它读取。

路径有空格

用英文引号包起来，例如 "C:\Program Files\JASP\JASPDesktop.exe"。

支持的 22 类分析

插件把你的原话识别成下面的方法，再调用本机 JASP 引擎计算。先给出计划让你确认，确认后才真正跑。

版本 0.2.0 在原来 17 类的基础上，增加了贝叶斯 Process、贝叶斯线性/广义混合模型、MIMIC 与潜变量增长曲线。

方法（对插件说）JASP 分析什么时候用 / 要点
描述与相关
descriptives
描述统计		Descriptives均值、标准差、频数。可以说“对年龄和绩效做描述统计”。
reliability
信度		reliabilityUnidimensionalFrequentist量表内部一致性（α / ω）。需要一组题项，例如 sat1 到 sat5。
correlation
相关		CorrelationPearson / Spearman / Kendall。可以说“看满意度和绩效的相关，用 Spearman”。
均值比较
ttest_independent
独立样本 t 检验		TTestIndependentSamples两组比较，例如男女在绩效上的差异。超过两水平会提示改用 ANOVA。
paired_ttest
配对 t 检验		TTestPairedSamples同一批人的前后测或配对观测。
anova
方差分析		Anova单因素或多因素。自动补齐交互项，水平数 > 2 时默认事后比较；可做简单效应与 Helmert 等对比。
ancova
协方差分析		Ancova分组比较并控制连续协变量。
rm_anova
重复测量方差分析		AnovaRepeatedMeasures宽格式、单一被试内因子，可叠加 1–2 个组间因子。含球形检验与 Greenhouse-Geisser 校正。
回归
regression
多元线性回归		RegressionLinear连续因变量的预测或解释，例如“年龄和满意度如何预测绩效”。
中介与调节（Process）
process
Process 中介/调节		ClassicProcessHayes 模型 1 / 4 / 6 / 7 / 8 / 14 / 15。中介默认 1000 次 bootstrap。可指定 FIML。
process_bayesian
贝叶斯 Process		BayesianProcess同一套模型的贝叶斯版本（blavaan / Stan）。说“贝叶斯中介”或“贝叶斯调节”。默认 3 条链、500 次 burn-in、1000 次抽样，可能需要几分钟。
因子分析
efa
探索性因子分析		exploratoryFactorAnalysis探索题项结构，至少 3 题。含 KMO / Bartlett、载荷与碎石图。
pca
主成分分析		principalComponentAnalysis降维与成分载荷。
cfa
验证性因子分析		confirmatoryFactorAnalysis需要在 options.factors 给出因子结构，例如 [{name, indicators}]。
结构方程
sem
结构方程模型		SEM需要 options.models 传入 lavaan 语法，例如 F1 =~ sat1 + sat2 + sat3。
plssem
PLS-SEM		PLSSEM偏最小二乘 / 复合测量。语法用 ->，并给出路径。
mimic
MIMIC 模型		MIMIC用多个指标定义一个潜变量，再用连续或二分变量预测它。至少 3 个指标、1 个预测变量。多于 2 水平的分类变量（如学历）不能直接当预测变量。
latent_growth
潜变量增长曲线		LatentGrowthCurve至少 3 个连续重复测量变量（宽格式，按时序）。默认拦截 + 线性；可以说“二次/三次”。时点默认 0, 1, 2, …，也可用 options.timings 指定。
混合模型
mixed_lmm
线性混合模型		MixedModelsLMM长格式。指定因变量、固定效应、随机分组（如被试 ID）。可说“随机斜率”。
mixed_glmm
广义线性混合模型		MixedModelsGLMM二项 / 泊松 / 高斯等分布族。说“二项广义线性混合模型”会选用 Bernoulli + logit。
mixed_blmm
贝叶斯线性混合模型		MixedModelsBLMM连续因变量的贝叶斯混合模型（rstanarm）。说“贝叶斯线性混合模型”。默认 MCMC 同上，首次可能需数分钟。
mixed_bglmm
贝叶斯广义线性混合模型		MixedModelsBGLMM贝叶斯 GLMM。说“贝叶斯广义线性混合模型”或“贝叶斯二项混合”。支持 Bernoulli、Poisson、高斯等族。

可以这样开口

“用 demo.csv，看 sat1 到 sat5 的信度，再做满意度与绩效的相关。”
“age 通过 sat_mean 影响 perf，做中介，用 bootstrap。”要贝叶斯版本就说：“做贝叶斯中介”。
“做 MIMIC：sat1 到 sat5 当指标，age 当预测变量。”
“拟合潜变量增长曲线，变量是 t1 到 t4。”
“以 score 为因变量，wave 和 condition 为固定效应，按 subject 做随机截距。”要贝叶斯或广义模型时，把“贝叶斯”“广义/二项”说清楚。
注意
  • 分析都在本机 JASP 引擎里跑，不会把原始数据传到网上。
  • 贝叶斯模型要抽样，比频率派慢；结果里应看后验估计、可信区间、R̂ 和有效样本量。
  • CFA / SEM / PLS-SEM 需要你提供模型结构或 lavaan 语法，插件不会凭空编模型。
  • 导出 .jasp 文件后，可用 JASP 打开并 Refresh 查看已写入的结果。

名词小抄

插件 / MCP
AI 和本地软件之间的“插头标准”。
API Key
模型服务的“钥匙”，像密码，不能给别人。
Base URL
模型服务的“地址”。

插件文件所在的文件夹，通常在 $HOME\.workbuddy\jasp-bridge。

JASP 自带计算引擎的一份副本，约 1.7 GB。
宿主
能装插件的聊天软件，比如 WorkBuddy、Cherry Studio。

常见问题

没装 JASP

先装 JASP（Microsoft Store 或官网桌面版）。插件不能代替 JASP。

提示找不到 Node

用带 node.exe 的便携包；或者安装 Node 20+。

WorkBuddy 看不到插件

检查 $HOME\.workbuddy\mcp.json，然后重启 WorkBuddy。

提示禁止运行脚本

用文档里的命令：powershell -ExecutionPolicy Bypass -File .\install.ps1

首次很慢

在复制约 1.7 GB 运行时，等几分钟；之后首次加载 worker 约 5–10 秒。

DeepSeek/豆包设置里没有 MCP

说明这个版本不支持本地插件。换 Cherry Studio 等支持 MCP 的客户端。

安全提醒

  • API Key 不要截图、不要发人、不要上传网盘。
  • CSV 和 JASP 都在本机，插件不上传原始数据。
  • 只有工具返回的结果表会进入模型对话。
  • 不要把 JASP 通过公网隧道暴露给云端智能体。
