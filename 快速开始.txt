JASP-Bridge 0.3.2 安装说明（2026-11-27）

这是文档和便携安装包。WorkBuddy 实际加载的是：
%USERPROFILE%\.workbuddy\jasp-bridge
只更新桌面这个文件夹，不会自动更新正在运行的插件。

当前能力：22 类分析（含 EFA / CFA / SEM、Process、混合模型，以及贝叶斯 Process、
贝叶斯线性/广义混合模型、MIMIC、潜变量增长曲线）。可以直接说“做 EFA / CFA / SEM”；
若未指定题项或因子，插件会按列名和前缀给出建议方案，标明为建议，确认后才执行。数据可直接加载 CSV / Excel（.xlsx .xls） / SPSS（.sav）。描述统计默认关闭 Shapiro-Wilk 与矩阵散点图，题项多时会更快；需要时再打开。
回归、配对 t、ANCOVA、ANOVA 仍标 beta。

官方便携包 jasp-bridge-0.3.2-portable.zip 约 41 MB，含插件代码、依赖、文档、示例
和 Windows node.exe，不含约 1.7 GB 的 JASP 运行时（安装时从本机 JASP 复制）。

源码与发布：https://github.com/nanple/jasp-bridge
便携包下载：https://github.com/nanple/jasp-bridge/releases/download/v0.3.2/jasp-bridge-0.3.2-portable.zip

最简版（推荐先试）：
把 jasp-bridge-0.3.2-portable.zip 拖进 WorkBuddy 对话框，发送：
"这是我下载的 JASP-Bridge 安装包。请帮我解压、检查本机 JASP、运行 install.ps1 安装，完成后告诉我怎么验证。不要覆盖已有的 runtime 和 sessions。"

如果 WorkBuddy 不能执行本地命令，再按下面手动安装。

非 WorkBuddy 用户（DeepSeek / 豆包 / 千问）：
见 SUPPORT-DEEPSEEK-DOUBAO.md 和 configs\README.md。

图文版：docs\visual-guide.pdf
详细功能、话术与常见坑：GUIDE.md
示例数据：examples\demo.csv、examples\factor-demo.csv、examples\mixed-demo.csv

前提：
- Windows 10/11 64 位
- 已安装 JASP（Microsoft Store 或官网桌面版）
- 不需要单独安装 R 或 jaspTools；官方 zip 已内置 node.exe
- 日常分析不需要访问 GitHub；运行时从本机 JASP 复制

手动安装：
1. 解压 jasp-bridge-0.3.2-portable.zip
2. 在解压后的文件夹空白处 Shift + 右键，选择"在终端中打开"
3. 运行：
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   只有 JASP 自动识别失败时，才需要加：
   -JaspPath "<你的JASP安装目录>\JASPDesktop.exe"
4. 首次会从本机 JASP 复制约 1.7 GB 运行时，请等待几分钟
5. 完成后重启 WorkBuddy
6. 在 WorkBuddy 里问："检查 JASP 状态"

本机安装位置：
%USERPROFILE%\.workbuddy\jasp-bridge

MCP 配置：
%USERPROFILE%\.workbuddy\mcp.json

运行时不在 zip 内，由安装脚本从用户自己的 JASP 复制。
